# Model 204 Data Processing Utility

This utility provides a robust framework for ingesting, processing, validating, and transforming data records within a Model 204 environment.

## Components

- `main.m204`: Entry point and execution controller.
- `processor.m204`: Core logic for data transformation and manipulation.
- `validator.m204`: Business rule validation and data integrity checks.

## Usage

1. Define your data records in the Model 204 dictionary.
2. Load the utility programs into your Model 204 session.
3. Execute `main` to initiate the processing pipeline.

## Requirements

- Model 204 Server Environment
- Appropriate user permissions for the target database.
