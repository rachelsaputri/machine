# LSE Data Processing Utility

A comprehensive data processing utility written in LSE (Lightweight System Execution).

## Features

- Data Ingestion
- Data Transformation
- Data Validation
- Reporting

## Usage

Run the main module:

```bash
lsel ./lse_data_processing_utility/main.lse
```

## Modules

- `main.lse`: Entry point
- `ingester.lse`: Data ingestion logic
- `transformer.lse`: Data transformation logic
- `validator.lse`: Data validation logic
- `reporter.lse`: Data reporting logic
