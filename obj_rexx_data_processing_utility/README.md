# Object REXX Data Processing Utility

This utility provides a robust data processing framework implemented in Object REXX. It is designed to handle data ingestion, validation, transformation, and reporting.

## Features
- Modular processing pipeline
- Built-in data validation
- Extensible transformer modules
- Configurable reporting

## Usage
Run the main script to initiate the processing pipeline:

```bash
rexx main.rex
```

## Components
- `main.rex`: Entry point for the application
- `ingester.rex`: Handles data ingestion from various sources
- `validator.rex`: Validates data against defined schemas
- `transformer.rex`: Transforms data according to business rules
- `reporter.rex`: Generates reports from processed data
- `config.rex`: Manages configuration settings
