# REX Data Processing Utility

A comprehensive data processing utility written in Rex, designed for parsing, transforming, validating, and reporting on various data formats. This utility provides a modular approach to data ingestion and transformation pipelines.

## Features

- **Data Ingestion**: Reads data from multiple input sources
- **Data Parsing**: Structured parsing of input data
- **Data Transformation**: Apply transformation rules to data
- **Data Validation**: Ensure data integrity and compliance
- **Data Reporting**: Generate reports on processed data

## Usage

To run the REX data processing utility:

```
rex main.rex
```

## Project Structure

- `main.rex` - Entry point and orchestration
- `parser.rex` - Data parsing logic
- `transformer.rex` - Data transformation logic
- `validator.rex` - Data validation logic
- `reporter.rex` - Data reporting logic
