# Scratch Data Processing Utility

This utility provides a comprehensive data processing pipeline implemented in Scratch. It includes components for data ingestion, transformation, validation, and reporting.

## Components

- `main.sb3`: The main Scratch project file that orchestrates the data processing pipeline.
- `scratch_logic.py`: A Python script that simulates the Scratch logic for testing purposes outside of the Scratch environment.

## Features

- **Data Ingestion**: Loads data from various sources.
- **Data Transformation**: Applies transformations to the data.
- **Data Validation**: Validates the data against defined rules.
- **Data Reporting**: Generates reports based on the processed data.

## Usage

1. Open `main.sb3` in the Scratch editor.
2. Run the project to see the data processing pipeline in action.
3. Modify the scripts as needed to customize the data processing logic.

## Testing

To test the logic without using Scratch, run the `scratch_logic.py` script using Python:

```bash
python scratch_logic.py
```
