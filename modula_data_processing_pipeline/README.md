# Modula Data Processing Pipeline

This is a modular data processing utility written in Modula-2.

## Features
- Data ingestion
- Simple transformation (uppercase conversion)
- Output formatting

## How to Build
1. Install a Modula-2 compiler (e.g., GNU Modula-2 or Modula-3).
2. Compile the main module:
   ```bash
   gm2 main.mod
   ```
3. Run the executable:
   ```bash
   ./a.out
   ```

## Usage
The program reads a string from standard input, converts it to uppercase, and prints the result.
