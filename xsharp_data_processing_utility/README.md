# X# Data Processing Utility

A complete, functional data processing utility written in X# for handling data ingestion, validation, transformation, and reporting.

## Features

- Data Ingestion
- Data Validation
- Data Transformation
- Data Reporting

## Usage

1. Ensure you have the X# compiler and runtime environment set up.
2. Run the main program using:
   ```
xsharp Main.xsharp
   ```

## File Structure

- Main.xsharp: The main entry point for the data processing utility.
- Ingestor.xsharp: Handles data ingestion.
- Validator.xsharp: Validates the ingested data.
- Transformer.xsharp: Transforms the validated data.
- Reporter.xsharp: Generates reports from the transformed data.

## Dependencies

- X# Compiler/Runtime
