# Genie Data Processing Utility

This utility is a data processing tool written in Genie. It provides a framework for ingesting, transforming, and validating data.

## Features
- Data Ingestion
- Data Transformation
- Data Validation

## Usage
1. Clone the repository.
2. Install Genie if not already installed.
3. Compile the utility using `genie genie_data_processing_utility.gs`.
4. Run the compiled executable.

## Dependencies
- Genie compiler
