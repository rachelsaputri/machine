# Beanshell Data Processing Pipeline

A modular data processing pipeline implemented in BeanShell.

## Components

- `main.bsh`: Entry point for the pipeline.
- `ingester.bsh`: Handles data ingestion from various sources.
- `transformer.bsh`: Applies transformation rules to the data.
- `validator.bsh`: Validates data against defined schemas or constraints.
- `reporter.bsh`: Generates reports and logs the processing results.

## Usage

1. Ensure BeanShell is installed.
2. Run the main script: `bsh main.bsh`.

## Configuration

Edit the `config.properties` file to set up data sources, transformation rules, and validation schemas.
