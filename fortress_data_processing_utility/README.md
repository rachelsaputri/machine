# Fortress Data Processing Utility

A modular data processing utility written in the Fortress programming language.

## Features
- Data ingestion from standard input
- Data validation and sanitization
- Data transformation capabilities
- Report generation

## File Structure
- `main.for`: Entry point
- `ingestor.for`: Handles data input
- `validator.for`: Validates data integrity
- `transformer.for`: Transforms data formats
- `reporter.for`: Generates output reports

## Usage
Compile the module and run:
fortress main.for
