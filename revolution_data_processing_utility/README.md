# Revolution Data Processing Utility

A robust, fully functional data processing utility written in **Revolution** (formerly LiveCode).

## Features

- **Data Ingestion**: Reads data from CSV, JSON, and plain text files.
- **Transformation**: Applies configurable transformations (e.g., uppercase, lowercase, trim).
- **Validation**: Ensures data integrity and format compliance.
- **Reporting**: Generates summary reports of processing results.

## Installation

1. Ensure you have the **LiveCode** environment installed.
2. Clone or download this repository.
3. Open `main.livecode` in LiveCode.

## Usage

1. Update the `pSourceFile` and `pOutputFile` variables in `main.livecode`.
2. Run the application using `LiveCode` or `Run LiveCode Engine`.
3. Check the output file for processed data.
