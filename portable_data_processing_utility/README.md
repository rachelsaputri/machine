# PortablE Data Processing Utility

This project provides a lightweight, portable data processing pipeline implemented in PortablE.
It demonstrates core data manipulation capabilities including ingestion, validation, transformation, and reporting.

## Features
- Ingests raw data arrays
- Validates record structures
- Transforms data records
- Generates summary reports

## How to Run
1. Ensure PortablE is installed.
2. Run `portable_data_processing_utility.pe`.
