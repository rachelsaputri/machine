# VBScript Data Processing Utility

A modular, production-ready VBScript utility for enterprise data processing tasks.

## Features
- **Ingest**: Reads and validates CSV data files.
- **Transform**: Performs data cleansing, formatting, and calculation.
- **Validate**: Checks for data integrity and business rule compliance.
- **Report**: Generates detailed CSV reports.
- **Export**: Saves processed data to new CSV files.

## Requirements
- Windows OS (XP or later)
- WSH (Windows Script Host) enabled
- VBScript engine

## Usage
1. Copy the `main.vbs` and utility modules to your project directory.
2. Configure the `config.cfg` file.
3. Run `cscript main.vbs` from the command line.
