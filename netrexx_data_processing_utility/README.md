# NetRexx Data Processing Utility

A comprehensive, fully functional data processing utility written in NetRexx.
This tool handles data ingestion, validation, transformation, and reporting.

## Features
- **Ingestor**: Reads raw data from files or standard input.
- **Validator**: Checks data integrity, format, and business rules.
- **Transformer**: Cleans, normalizes, and transforms data structures.
- **Reporter**: Generates structured reports (CSV, JSON, or Text).

## Usage
Compile and run using the NetRexx compiler or interpreter:

```bash
netrexx -i NetRexxDataProcessor -o NetRexxDataProcessor.class
java NetRexxDataProcessor input.txt output.csv
```

## Requirements
- Java Runtime Environment (JRE) 8+
- NetRexx Compiler
