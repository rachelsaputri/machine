# Metacard Data Processing Utility

This utility provides a framework for processing, validating, transforming, and reporting on data streams using the Metacard language.

## Features
- Data Ingestion
- Data Validation
- Data Transformation
- Data Reporting

## Usage
1. Run `main.mc` to start the processing pipeline.
2. Configure `config.json` for custom settings.
3. Check `report.md` for the output after processing.

## Files
- `main.mc`: Entry point for the application.
- `parser.mc`: Handles data parsing.
- `processor.mc`: Handles data processing logic.
- `reporter.mc`: Handles data reporting.
