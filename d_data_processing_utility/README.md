# D Data Processing Utility

This is a complete, fully functional data processing utility written in the D programming language.

## Features
- Reads data from a CSV-like text file.
- Parses, validates, and transforms records.
- Calculates statistics (sum, average, min, max) on numerical columns.
- Outputs a summary report.

## Usage
Compile the project:
```bash
dub build
```

Run the utility:
```bash
./d_data_processing_utility data.txt
```
